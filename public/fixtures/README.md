# Hand-tracking fixtures

Recorded `HandFrame` streams (21 landmarks, handedness, timestamp; **no images**) that replay through
the same `Tracker` interface as the camera. Load any of them with `?source=fixture:<name>`.

Real recordings: made on 2026-11-07 by the repo owner (one person, right hand), indoors, laptop
webcam, with the dev capture hotkey (Shift+R, last 10 s). Lighting: _not noted; fill in_.

Frames where no hand was detected are not stored. So a gap in the timestamps means the hand was out of
view, and the end of a file is the last frame the hand was seen. Where the 10 s window reached
back into the previous take (`swipe-left`, `swipe-right`, `open-palm-hold`, `fist-hold`), every frame
before the no-hand gap that separates the takes was cut. Nothing else was edited.

| Fixture | Length | Contains | Used for |
|---|---|---|---|
| `pinch-twice` | 6.7 s | Pointing hand: pinch, release, pinch, release. | Exactly 2 clicks (007) |
| `swipe-left` | 4.3 s | Still open hand, one fast swipe to the user's left (raw x 0.30 → 0.76), still again. | Exactly 1 `next` (010) |
| `swipe-right` | 3.7 s | Still open hand, one fast swipe to the user's right (raw x 0.81 → 0.18), still again. | Exactly 1 `prev` (010) |
| `fidget-10s` | 7.9 s | Natural movement with no intended gesture: includes near-pinches, curled fingers, a brief exit from view and handedness flicker. | 0 clicks, 0 swipes, no holds |
| `hand-leaves-mid-pinch` | 3.7 s | Pinch, then the hand leaves the frame while still pinched; the file ends mid-pinch. | `release` and no stuck press (007). Tests should feed a `null` frame after the last one. |
| `open-palm-hold` | 3.3 s | Open palm held still. | Exactly 1 `pause` (009) |
| `fist-hold` | 3.6 s | Hand closes into a fist and holds. Thumb-to-index distance dips near pinch range inside the fist. | Exactly 1 `clear` (009); must not click |
| `demo-showcase` | 10.0 s | Free movement with several pinches, for "Watch a demo". | Demo playback |
| `synthetic-wave` | 4.0 s | Generated by `npm run fixtures:synthetic`: an open right hand waving. | Smoke and privacy e2e tests |

Raw landmark x is in camera space (not mirrored), so moving to the user's left increases x.
