## What to build
- Fixture format: JSON `{ name, fps, frames: HandFrame[] }`, stored where both the app and the tests can load them (e.g. `public/fixtures/`).
- `createTracker({ fixture })` replays the frames with their recorded timestamps through **the same interface** as the camera tracker, looping for demos.
- `?source=fixture:<name>` makes the whole app run from a fixture instead of the camera.
- A **synthetic starter fixture** (`synthetic-wave`), generated by a small script from a template hand pose with a little motion, so everything is testable before real recordings exist.
- A dev-only capture hotkey (for example `Shift+R`, only in dev builds or behind `?dev`) that downloads the last N seconds of live `HandFrame`s as a fixture file. Issue 005 uses it.
- A **"Watch a demo"** button on every failure screen, which plays the demo fixture with the skeleton drawn over a neutral background.
- Playwright: a smoke test that loads `?source=fixture:synthetic-wave`, sees the canvas rendering, and checks that a failure screen shows both buttons. Add it to CI.

## Acceptance criteria
- [x] Unit tests for the fixture player's timing and looping, using fake timers.
- [x] `?source=fixture:synthetic-wave` shows a moving skeleton with no camera prompt.
- [x] The capture hotkey downloads a valid fixture file (manual check).
- [x] Playwright runs green locally (CI: verify on the next push).
